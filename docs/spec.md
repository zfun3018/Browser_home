# 浏览器首页当前规格

## 运行时

- FastAPI 后端和 React/Vite 前端组成首页服务。
- 书签、分组、布局和搜索设置保存在 `homepage-data` 下的 SQLite 数据库。
- Obsidian 笔记直接读写用户指定的 Markdown 文件，并保留冲突副本。
- 本地备份服务归档 SQLite 数据库、图标缓存、冲突副本、笔记和原生服务配置。
- 两个服务由 WinSW 注册为自动启动的 Windows 服务，只监听 `127.0.0.1`。

## 数据要求

- 迁移保留现有书签和分组 ID，确保布局映射不变。
- 书签编辑使用乐观并发校验，冲突时返回刷新提示。
- 导入前先生成当前数据的回滚 ZIP，校验通过后才替换数据。
- 新备份使用 `manifest.formatVersion = 2` 和 `storageBackend = sqlite`；旧格式 ZIP 只保留，不保证可导入。

## 安全边界

- 写操作要求本机同源请求。
- 浏览器扩展收藏接口使用文件中的捕获令牌。
- 备份导入限制 ZIP 路径、大小、文件数、哈希和 SQLite 完整性。
- 图标抓取只访问经过校验的公网 HTTP(S) 地址，并限制重定向和响应大小。
