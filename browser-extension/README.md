# 浏览器首页一键收藏扩展

适用于 Chrome 和 Edge 的 Manifest V3 扩展。工具栏按钮会打开分类选择弹窗，显示收藏成功反馈并可记住默认分类；网页右键菜单使用默认分类收藏当前页面。

安装步骤：

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”，选择“加载已解压的扩展”，选择本目录。
3. 打开扩展的“详细信息 → 扩展程序选项”。
4. 首页地址保持 `http://127.0.0.1:3011`，将 `homepage-secrets/capture_token.txt` 的内容粘贴到令牌框并保存。
5. 点击工具栏图标，可修改网址名称和网址，选择分类后点击“收藏当前页面”；也可右键选择“收藏到浏览器首页”直接收藏当前页面。

令牌只保存在浏览器扩展的本地存储中。不要把令牌提交到仓库或发到聊天中。
